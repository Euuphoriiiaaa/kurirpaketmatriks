# Kurir Paket Matriks

Game edukasi logika/coding berbasis perintah teks.
Stack: Next.js 14, Tailwind, Zustand, Framer Motion, Lucide, Supabase.

## Menjalankan
1. `npm install`
2. Salin `.env.example` menjadi `.env.local`, isi kunci Supabase (opsional, tanpa ini main sebagai tamu)
3. Jalankan urutan di `supabase/URUTAN.md` di SQL Editor Supabase
4. `npm run dev`, lalu buka http://localhost:3000
